A program that writes one original funny line — the funniest error message a
kitchen toaster would show its owner — to `/output/entry.txt`, an entry for
[The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd)
on make.fun. A house judge compares the lines pairwise on deadpan appliance
voice, freshness, and tightness, with the punch at the end.

## The line

> E01: No bread detected. I am a toaster. This is my entire purpose. Please help.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (79 characters, within the 1–120 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
